# 物品收纳模块 · 完整技术文档

> 适用范围：个人工作台「物品收纳」分区（`#page-items` 及其全部子页、弹层）。  
> 文档生成依据：当前线上版本 **v32** 的 `index.html` / `css/items.css` / `js/items.js`（只读分析，未做任何改动）。  
> 数据"数据库"实现：浏览器 **localStorage**（每台设备各一份，手机端与电脑端不共享）。

---

## 一、数据库表（localStorage 键）

本模块共读写 4 个 localStorage 键，相当于 4 张"表"。每次 `save()` 主表会同步写一份 `*_backup` 备份键。

| 表名（键）                    | 类型 | 内容                   | 读取位置     | 写入位置     |
| ------------------------ | -- | -------------------- | -------- | -------- |
| `wb_items_v2`            | 数组 | 物品主表（每条物品含批次数组、取用数组） | `load()` | `save()` |
| `wb_item_categories_v2`  | 数组 | 分类表（自定义一级/二级分类）      | `load()` | `save()` |
| `wb_items_settings_v2`   | 对象 | 全局设置（视图、排序、筛选、分类页签等） | `load()` | `save()` |
| `wb_items_tombstones_v2` | 数组 | 删除同步墓碑（已删除的物品/分类 id） | `load()` | 同步删除时    |

### 1.1 物品主表 `wb_items_v2`（数组，元素 = item 对象）

| 字段                                               | 类型                       | 含义                 | 来源页面/控件                        | 写入函数                            |
| ------------------------------------------------ | ------------------------ | ------------------ | ------------------------------ | ------------------------------- |
| `id`                                             | string(uuid)             | 物品唯一 ID            | 新增时 `uuid()` 生成                | `saveItemForm()`                |
| `name`                                           | string                   | 物品名称               | 添加页名称框 / 编辑页名称框                | `saveItemForm()` / `saveEdit()` |
| `icon`                                           | string                   | 图标（emoji 或图片路径）    | 图标选择器                          | 同上                              |
| `categoryId`                                     | string                   | 所属分类 ID（关联分类表 id）  | 分类选择器                          | 同上                              |
| `purchaseDate`                                   | string `YYYY-MM-DD`      | **入库日期**（决定批次唯一标识） | 添加页"入库日期"行                     | `saveItemForm()`                |
| `productionDate`                                 | string                   | 生产日期               | 添加页"生产日期"行                     | 同上                              |
| `location`                                       | string                   | 存放位置               | 添加/编辑页"存放位置"                   | 同上                              |
| `memo`                                           | string                   | 备注                 | 添加/编辑页"备注说明"                   | 同上                              |
| `retiredDate`                                    | string                   | **退库日期（单个物品层级）**   | 添加页"退库日期（选填）" / 编辑页单件退库        | `saveItemForm()` / `saveEdit()` |
| `expectedDaily`                                  | string/number            | 预期日均/单次成本          | 添加页"预期日均"                      | `saveItemForm()`                |
| `usageCount`                                     | string/number            | 使用次数               | 添加页"使用次数"                      | 同上                              |
| `maintenanceTotal`                               | string/number            | 累计维护支出             | 添加页"累计维护支出"                    | 同上                              |
| `calcMode`                                       | `'time'\|'freq'\|'none'` | 计算方式               | 添加页"计算方式"标签页                   | 同上                              |
| `avgPrice`                                       | number                   | 购买均价（=维护时填的单价，不重算） | 取最后批次 `unitPrice`              | `saveItemForm()` / `saveEdit()` |
| `autoTakeOne`                                    | bool                     | 入库后立即取用 1 件        | 批量页"入库后立即取用 1 件"开关             | `saveItemForm()`                |
| `batches`                                        | **数组**                   | 入库批次列表（核心）         | 见 1.1.1                        | 同上                              |
| `usings`                                         | **数组**                   | 取用记录列表             | 见 1.1.2                        | `saveUse()`                     |
| `createdAt`                                      | ISO 字符串                  | 创建时间               | 新增时 `new Date().toISOString()` | `saveItemForm()`                |
| `updatedAt`                                      | ISO 字符串                  | 最后修改时间             | 每次保存                           | 各保存函数                           |
| `pinned`                                         | bool                     | 是否置顶（最多 10 个）      | 卡片置顶按钮                         | `togglePin()`                   |
| `starred`                                        | bool                     | 收藏标记（**功能暂停**，见下）  | 五角星按钮（仅弹提示）                    | `groupItems()` 合并时保留            |
| `qty`/`price`/`totalPrice`/`expiryDate`          | 兼容字段                     | 旧模型残留，按批次重算        | 自动计算                           | `saveItemForm()`                |
| `stockQty`/`inUseQty`/`scrappedQty`/`retiredQty` | 兼容字段                     | 旧模型残留（报废/退役恒为 0）   | 自动计算                           | 同上                              |

#### 1.1.1 批次对象 `item.batches[]`（入库批次）

| 字段            | 类型                        | 含义                         | 生成规则                                                                                                   |
| ------------- | ------------------------- | -------------------------- | ------------------------------------------------------------------------------------------------------ |
| `id`          | string                    | **入库批次唯一标识符**              | `dateToBatchId(purchaseDate)` → `YYYYMMDD入库`（如 `20260904入库`）。**同日多次入库自动合并为一条**（`mergeSameDayBatches`）。 |
| `date`        | string                    | 入库日期                       | = 该次维护填的"入库日期"                                                                                         |
| `quantity`    | number                    | 本批次数量                      | 批量页数量 / 单个页固定 1                                                                                        |
| `unitPrice`   | number                    | 本批次单价                      | 批量页"物品单价" / 单个页"购入价格"                                                                                  |
| `totalPrice`  | number                    | 本批次总价                      | `unitPrice*quantity`                                                                                   |
| `validity`    | `{value:365, unit:'day'}` | 有效期结构（占位，实际用 `expiryDate`） | 固定                                                                                                     |
| `expiryDate`  | string `YYYY-MM-DD`       | 有效期截止日                     | 有效期选择器                                                                                                 |
| `retiredDate` | string                    | **本批次退库日期**（按批次退库）         | 编辑页"按批次退库日期" / 单件同步                                                                                    |
| `note`        | string                    | 备注                         | = 物品 `memo`                                                                                            |

#### 1.1.2 取用对象 `item.usings[]`

| 字段         | 类型     | 含义                |
| ---------- | ------ | ----------------- |
| `batchId`  | string | 取自哪个批次（= 批次 `id`） |
| `date`     | string | 取用日期              |
| `quantity` | number | 取用数量              |
| `note`     | string | 取用备注              |

### 1.2 分类表 `wb_item_categories_v2`（数组，元素 = category 对象）

| 字段                      | 类型          | 含义                                                     |
| ----------------------- | ----------- | ------------------------------------------------------ |
| `id`                    | string      | 分类唯一 ID（`cat_uncategorized` = 未分类固定 ID；`sys_*` = 系统分类） |
| `name`                  | string      | 分类名称                                                   |
| `icon`                  | string      | 图标（emoji 或图片路径，如 `assets/items/icons/...`）             |
| `parentId`              | string|null | 一级分类为 `null`，二级分类 = 父级 id                              |
| `system`                | bool        | 是否系统内置（true=只读，不可增删改）                                  |
| `createdAt`/`updatedAt` | ISO         | 时间戳（迁移/合并时补）                                           |

> 系统分类（18 个一级 + 233 个二级 + 图标映射）由 `SYSTEM_PRIMARY` / `SYSTEM_SECONDARY` / `SYSTEM_ICON_MAP` 常量在前端硬编码，不入库；自定义分类才写入此表。

### 1.3 设置表 `wb_items_settings_v2`（单对象）

| 字段           | 类型                                            | 默认             | 含义               |
| ------------ | --------------------------------------------- | -------------- | ---------------- |
| `hideAmount` | bool                                          | false          | 金额是否隐藏（总资产/日均打码） |
| `viewMode`   | `'grid'\|'list'`                              | 'grid'         | 总览页卡片视图（网格/清单）   |
| `sortField`  | string                                        | 'purchaseDate' | 排序字段（见排序弹层）      |
| `sortDir`    | `'asc'\|'desc'`                               | 'asc'          | 排序方向             |
| `filters`    | `{categories:[], statuses:[], starred:false}` | 空              | 筛选条件             |
| `catTab`     | `'my'\|'sys'`                                 | 'my'           | 分类页当前页签          |
| `sysCatChip` | string                                        | 'all'          | 系统分类一级 chip 选中项  |

### 1.4 墓碑表 `wb_items_tombstones_v2`（数组）

存已删除的物品/分类 id 列表，用于云端同步时把删除动作传播到其他设备。`load()` 时恢复进内存 `TOMB`。

## 二、页面与功能详述

> 排版约定：每个子页都是 `#page-items` 下的 `.i-subpage`，通过 `showSubpage(name)` 切换 `active` 类显隐。

### 2.1 总览页（`#i-subpage-overview`）—— 物品统计

**顶部标题**：`<h1>物品统计</h1>`，整行居中（`justify-content:center`，`font-size:clamp(18px,5.4vw,24px)`）。

#### 总资产卡片 `.i-asset-card`

- **渐变背景** `linear-gradient(135deg,#E8F1E3 0%,#FFFFFF 100%)`，圆角 24px，内边距 16px。
- **总资产** `#iTotalAsset`：取自 `groupItems()` 的 `totalAsset`（**仅未退库批次**合计），格式 `¥xxxx.xx`。**取数表**：`wb_items_v2` → `batches[].totalPrice`（经 `getActiveBatches` 过滤退库）。点击**眼睛按钮 `#iEyeBtn`** → 切换 `settings.hideAmount`，显示 `¥ ****`。
- **平均每日成本** `#iAvgDailyCost`：取自 `groupItems().avgDailyCost`（各物品 `getItemDailyCost` 之和，退库批次不计），格式 `¥xx.xx`。
- **物品容量** `#iCapacityText` / 进度条 `#iCapacityFill`：取自 `groupItems().categoryCount`（合并后物品组数），显示 `N / 9999`，进度条宽度 `min(count/9999*100,100)%`。**取数表**：`wb_items_v2`（按 名称+一级+二级+图标 合并去重）。

#### 即将到期模块 `#iExpiringModule`（无到期项则 `display:none`）

- 标题"即将到期" + "查看全部"（点击 `showSubpage('expiring')`）。列表取 `getExpiringItems()`（有效期距今 ≤5 天的物品），最多展示 5 条，复用清单卡片样式。

#### "我的物品"栏 `#iItemsContainer` + 工具栏 `.i-section-bar`

- 标题 `<h2>我的物品</h2>`（左对齐，`clamp(15px,4.4vw,20px)`），右侧 4 个工具按钮：
  - **筛选 `#iFilterBtn`** → 打开筛选弹层，写入 `settings.filters`。
  - **排序 `#iSortBtn`** → 打开排序弹层，写入 `settings.sortField/sortDir`。
  - **画廊 `#iGalleryBtn`** → 切换 `settings.viewMode`（grid/list），按钮文案随当前视图变化（"画廊"/"清单"）。
  - **同步 `#iSyncBtn`** → 打开数据同步弹层。
- 列表区：无数据时显示空状态（`i-empty` 插画 + "还没有物品，点击右下角添加吧"）；有数据时按 `settings.viewMode` 渲染网格 `.i-grid`（2/3/4 列自适应）或清单 `.i-list`。
  - **网格卡片 `.i-grid-card`**：图标 + 名称 + 日均成本 `¥x.xx/日` + 置顶按钮。点击卡片（非按钮）→ `showDetail(group)`。
  - **清单卡片 `.i-list-card`**：图标(72×72) + 名称 + 日均 + 4 列统计（库存/在用/报废/退役）+ 底部"买入均价/总价值" + 置顶按钮。**"报废""退役"两列恒为 0**（新批次模型无此概念，兼容字段 `scrappedQty/retiredQty` 恒 0）。
  - **五角星（收藏）按钮 `#i-star/.i-list-star`**：**逻辑暂停使用** —— 原应为切换 `item.starred` 收藏态；当前仅 `showCenterToast('收藏功能暂未启用')`，不做任何数据变更。
  - **置顶按钮 `.i-action-pin`**：点击 `togglePin(group)`，最多 10 个（超出弹"最多可置顶 10 个物品"），写入各 `item.pinned`，卡片左侧出现绿色标记条。

#### 悬浮添加按钮 `.i-fab`（右下角 "+"）

点击 → `openAddItem('single')`，进入添加物品页。

### 2.2 添加物品页（`#i-subpage-add`）

**顶部标题**：换行居中（`.i-header-stacked`）：第一行"返回"按钮，第二行 `<h1>添加物品</h1>`（`clamp(18px,5vw,22px)`，整行居中）。  
**标签页**：`#iFormTabSingle`(单个物品) / `#iFormTabBatch`(批量物品)，切换显示 `#iSingleFields` / `#iBatchFields`。  
**底部操作**：`取消 #iCancelItemBtn2`（`showSubpage('overview')`）/ `✓保存物品 #iSaveItemBtn`（`saveItemForm()`）。

#### 2.2.1 单个物品表单 `#iSingleFields`

| 字段/控件                           | 存表字段                                      | 逻辑                                 |
| ------------------------------- | ----------------------------------------- | ---------------------------------- |
| 名称 `#iName`                     | `item.name`                               | 必填，空则提示                            |
| 图标 `#iIconBtn`                  | `item.icon`                               | 打开物品图标选择器                          |
| 分类 `#iCategoryTrigger`          | `item.categoryId`                         | 打开分类滚轮选择器（仅一级）                     |
| 购入价格 `#iPrice`                  | 新批次 `unitPrice`/`totalPrice`              | 单个物品固定数量 1，总价=单价                   |
| 预期日均成本 `#iExpectedDaily`        | `item.expectedDaily`                      | 选填                                 |
| **入库日期 `#iPurchaseDate`**       | `item.purchaseDate` + 批次 `date` + 批次 `id` | **默认值 = 今天**；决定批次唯一标识 `YYYYMMDD入库` |
| 生产日期 `#iProductionDate`         | `item.productionDate`                     | 默认今天                               |
| **退库日期（选填）`#iRetireDate`**      | `item.retiredDate` + 单批次 `retiredDate`    | 选填；维护且日期 ≤ 今天则不计入总资产/日均            |
| 有效期 `#iExpiryDate`              | 批次 `expiryDate`                           | 必填（打开有效期弹层），空则提示                   |
| 计算方式 `calcMode`(time/freq/none) | `item.calcMode`                           | 三个标签页单选                            |
| 使用次数 `#iUsageCount`             | `item.usageCount`                         | 选填                                 |
| 累计维护支出 `#iMaintenance`          | `item.maintenanceTotal`                   | 选填                                 |
| 存放位置 `#iLocation`               | `item.location`                           | 选填                                 |
| 备注说明 `#iMemo`                   | `item.memo`                               | 选填，同时作为批次 `note`                   |

#### 2.2.2 批量物品表单 `#iBatchFields`

| 字段/控件                           | 存表字段                  | 逻辑                                   |
| ------------------------------- | --------------------- | ------------------------------------ |
| 名称 `#iBatchName`                | `item.name`           | 必填                                   |
| 图标 `#iBatchIconBtn`             | `item.icon`           | 同单件                                  |
| 分类 `#iBatchCategoryTrigger`     | `item.categoryId`     | 复用单件选择器                              |
| 物品数量 `#iQty`(步进器)               | 批次 `quantity`         | 必须 >0                                |
| 物品单价 `#iBatchUnitPrice`         | 批次 `unitPrice`        | —                                    |
| 物品总价 `#iBatchTotalPrice`        | 批次 `totalPrice`       | 空则自动 = 单价×数量                         |
| 入库日期 `#iBatchPurchaseDate`      | 同单件                   | 默认今天                                 |
| 生产日期 `#iBatchProductionDate`    | 同单件                   | 默认今天                                 |
| 有效期 `#iBatchExpiryDate`         | 批次 `expiryDate`       | 必填                                   |
| **退库日期（选填）`#iBatchRetireDate`** | 批次 `retiredDate`(本批次) | 选填；**按批次各自退库**，不写 `item.retiredDate` |
| 入库后立即取用 1 件 `#iAutoTakeOne`(开关) | `item.autoTakeOne`    | 开启则保存后自动写一条 `usings`                 |
| 存放位置 `#iBatchLocation`          | `item.location`       | —                                    |
| 备注 `#iBatchMemo`                | `item.memo`           | —                                    |

> **保存 `saveItemForm()` 写入逻辑**：新增 → `item.batches=[新批次]`、`item.usings=[]`、初始化兼容字段；**编辑模式 → 仅 `item.batches.push(新批次)` 并 `mergeSameDayBatches` 合并同日批次，`usings` 保留不重置**（修复了旧版覆盖历史批次的 bug）。批次 `id` 一律 `dateToBatchId(入库日期)`。

### 2.3 我的分类页（`#i-subpage-categories`）

**顶部标题**：换行居中 —— "返回" + `<h1>我的分类</h1>` + 副标题"让每一件物品都有清晰的归处"。  
**搜索框** `#iCatSearch` + 放大镜按钮 `#iCatSearchBtn`：模糊匹配（包含匹配 + 子序列匹配），同时搜我的/系统一二级。  
**页签** `#iCatTabMy`(我的分类) / `#iCatTabSys`(系统分类（只读）)。  
**新增一级分类** `#iAddPrimaryBtn`（仅"我的分类"页签显示）。

#### 我的分类（tab=my）

- 渲染 `customPrimaryCategories()`（排除未分类），每个一级分类一个 `.i-cat-group`：标题 + 子分类数 + 操作（编辑✏️ / 删除🗑 / 加子分类➕ / 展开⌄）。
- 展开后显示子分类 `.i-cat-child`（图标 + 名称 + 编辑/删除）。
- 搜索无结果 → 显示"未找到相关分类"空状态卡片 `.i-cat-nofound`（**占满整行、右缘对齐屏幕**，见第五章），含"新增为一级分类"按钮。

#### 系统分类（只读）（tab=sys）

- 顶部横向 chip 行 `#iSysChipRow`（全部 + 18 个一级，可拖拽滚动），选中写入 `settings.sysCatChip`。
- 下方 2 列网格 `#iSysGrid` 展示二级分类卡片 `.i-sys-card`（图标+名称）；点击卡片 → 直接 `openAddItem('single', null, 该分类id)` 预填分类去添加物品。
- 搜索无结果 → 同样显示 `.i-cat-nofound` 占满整行卡片（含"清空搜索"按钮）。

### 2.5 物品档案页（`#i-subpage-detail`）

**顶部标题**：换行居中 —— "返回" + `<h1>物品档案</h1>`。  
进入时隐藏右下角 FAB（避免与底部栏冲突）。

#### 顶部大卡片 `.i-detail-hero`

- **批量角标** `#iDetailBatch`（"批量"）：当 `batches.length>1 || 总入库>1` 显示，否则 `i-hide`。
- **收藏星** `#iDetailStar`：**逻辑暂停使用** —— 点击仅 `showCenterToast('收藏功能暂未启用')`，不切换 `starred`。
- 图标 + 名称 + 日均成本 `¥x.xx/日`（`g.dailyCost`）。
- 三列统计：当前库存 / 总入库量 / 已取用（`g.currentStock/totalIn/totalUsed`）。

#### 已入库天数模块 `.i-detail-days`

- "已入库 N 天"（维护当天为第 1 天）+ "已使用 X%" + 进度条（按 `totalUsed/totalIn`）。

#### 库存档案 `.i-detail-section`

| 行                                                                | 取值                      | 说明                                                                   |
| ---------------------------------------------------------------- | ----------------------- | -------------------------------------------------------------------- |
| 购买均价 `#iDetailAvgPrice`                                          | `g.avgPrice`            | —                                                                    |
| 购买总价 `#iDetailTotalPrice`                                        | `g.totalPrice`          | 有效批次合计                                                               |
