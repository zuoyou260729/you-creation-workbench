柚
柚工坊 安装到桌面，像 APP 一样用（橘色"柚"图标，无浏览器角标）

如何安装（无浏览器角标）

用手机 Chrome 浏览器 打开本页面：

  1. 若桌面已有带 Chrome 角标的旧图标，先长按它选「移除 / 卸载」——留着它 Chrome 就不会再弹干净安装框。
  2. 点右下角 ⋮ 菜单，找并点 「安装应用」（注意：要选"安装应用"，不是"添加到主屏幕"；后者在 OPPO 上会变成带角标的书签）。
  3. 在 Chrome 弹出的安装确认中点「安装」，桌面即出现干净的橘色"柚"图标。

如果 Chrome 菜单里没有「安装应用」，说明安装提示被暂时屏蔽了：直接点本页底部「添加」按钮，让 Chrome 自己弹出安装框再确认即可。微信里打开需先「在浏览器打开」。
